# WorkBuddy 全自动成长系统 项目总需求

## 一、产品定位
WorkBuddy多账号无人值守自动化工具，完全模拟真人操作路径，自动完成每日签到、19个成长任务、积分领取全流程，不触发风控。用户仅需启动后点击执行，无需人工干预，即可完成所有账号的每日任务。

## 二、核心目标
1. 自动完成所有账号每日API类任务，签到、领奖励、盲盒、猫猫旅行等
2. 自动完成所有可自动化的UI类成长任务，拿到对应积分
3. 所有任务完成、积分到账后自动切换下一个账号，全程无人值守
4. 提供可视化Web工作台，支持全账号执行、单账号执行、单任务重跑、随时停止，清晰展示进度与日志

## 三、统一执行铁律（唯一标准，无特殊任务）
所有任务逻辑完全统一，不做特殊标注，不额外加特殊规则：
1. **串行操作铁则**：单客户端仅支持串行操作，一个任务操作完成、验证会话真的创建、任务已经开始执行、页面状态稳定后，再操作下一个任务，绝对不并行、不批量并发，避免页面混乱、找不到入口。
2. **发射即走规则**：确认任务发起成功后立刻进入下一个任务，不等AI完整回复、不等报告生成；所有任务发起完成后，统一轮询服务端进度，未计分的任务再补做。
3. **切号唯一标准**：只有当前账号所有可自动化任务全部计分、所有积分全部到账、统一复核补做完成后，才切换下一个账号，绝对不按固定时间预算强制切号。
4. **状态判断规则**：所有等待环节不写死固定时间，仅判断页面/元素是否加载完成、服务端进度是否更新；加载失败就刷新/重试，避免电脑性能卡顿导致时间bug。
5. **删除规则**：所有临时创建的内容（定时任务、临时会话），必须等服务端确认积分到账后才能删除，没拿到积分绝对不删除。
6. **任务初始判断逻辑**：
   - 第一步拉取全部任务+服务端最新进度，已完成的任务直接标记完成、跳过不执行
   - 符合以下三类的任务标记「需人工跳过」：需要人工扫码、需要付费/捐款、任务本身无积分
   - 其余所有任务全部标记待完成，正常执行，不提前硬编码跳过项。

## 四、两类特殊任务提示词规则（普通专家 vs 专家团，二者完全不同）
### 1. 专家团任务（召唤3个团队）
- 必须清空输入框内原有预填引导语，绝对不能保留/追加
- 仅发送固定提示词：`请让你们团队每个成员介绍一下自己的团队能力。`
- 该提示词直接触发团队召集子专家、成员介绍能力的TeamCreate事件，服务端认事件直接计分，不需要团队做实际任务、出报告
- 保留原有引导语会导致团队反问要资料、确认方案、提问需求，直接卡住不计分。

### 2. 普通单个专家任务（召唤5个专家、轻量云专家等）
- 统一规则：召唤专家后，保证专家直接完成交付，绝对不能出现反问用户、索要资料、要求确认方案的情况，专家直接给出完整回复即计分。

## 五、重点易漏步骤任务（少一步即不计分）
1. **资料库任务**：必须依次打开6份文档，每份加载完成后滚动到最底部读完；6份全部读完后，点击最后一份文档底部「进一步了解WorkBuddy资料库」外链，打开外链页面后滚动到最底部读完，少任何一步都拿不到积分。
2. **所有模板相关任务（设计创意模式、使用5个模板、灵感任务）**：
   - 不写死固定入口/分类，动态遍历扫描，优先选模板最多的日常任务分类；代码开发分类下仅网站设计有模板，其余无模板分类（生成图片/生成视频/品牌设计等）全部自动跳过
   - 维护账号级全局模板账本，该账号在任何任务里用过的模板统一标记，仅选择从未使用过的不同模板
   - 选中模板点「做同款」，处理替换弹窗，确认提示词填入后发送，验证发起成功并全局标记后再操作下一个，不能直接点提示词发送。
3. **和平精英主题**：如果当前已经是和平精英主题，必须先切换到其他主题，确认切换生效后，再切回和平精英主题，直接点击同主题不触发计分。

## 六、需人工跳过任务（符合条件才标记，不提前硬编码）
1. 体验「公益专家」：需付费捐款
2. 关注「腾讯WorkBuddy」官方公众号：需微信扫码
3. 参与「夜猫子」夜间折扣活动：非夜间执行时段
以上任务符合条件才标记跳过，其余所有任务正常执行，已完成自动跳过。
