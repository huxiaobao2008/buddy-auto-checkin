# WorkBuddy 全自动成长系统 工作流程文档

## 一、启动流程
1. 双击桌面一键启动脚本
2. 自动清理旧残留进程
3. 检查WorkBuddy客户端，未启动则自动拉起带CDP 9222调试端口的客户端，等待就绪
4. 启动本地Web服务（默认端口8765，仅监听127.0.0.1）
5. 自动打开浏览器进入工作台页面，扫描所有启用账号，准备执行。

## 二、三种执行粒度
系统支持三个层级的执行，满足不同场景需求：
1. **一键全自动**：遍历所有启用账号，执行完整两阶段流程，全程无需干预
2. **执行本账号**：仅执行选中的单个账号完整流程
3. **单任务执行**：仅执行当前账号下指定的单个任务，用于单独补做失败任务

---

## 三、完整执行全流程
### 阶段一：纯API管线（全账号串行，直接调接口，不操作UI）
按账号依次执行，单个账号跑完所有API任务自动切换下一个账号，所有账号API全部完成后才进入阶段二。
单个账号API执行顺序：
1. 每日签到
2. 领取Buddy
3. 开启盲盒
4. 派猫猫旅行
5. 出行到达奖励领取
6. 成长伙伴状态检查
7. 成长热度点亮
8. 成长任务接取

所有API任务统一逻辑：先读服务端进度，已完成自动跳过，未完成正常调用接口执行。

---

### 阶段二：UI管线（逐账号串行，单客户端严格串行操作，绝对不并行）
所有账号API完成后，逐账号进入UI阶段，每个账号流程如下：
#### 第一步：账号初始校验与任务分类
1. 切换到目标账号，通过账号闸校验当前客户端UID与目标账号匹配
2. 拉取全部19个任务+服务端最新进度
3. 统一分类标记：
   - 服务端已完成 → 标记完成，跳过不执行
   - 需扫码/付费/无积分 → 标记需人工跳过
   - 其余所有任务 → 标记待完成，进入串行执行队列

#### 第二步：串行执行普通会话型任务（确认发起成功即走，不等AI完整回复）
严格按顺序一个一个执行，每个任务点击发送后，验证会话真的创建、任务已经开始执行，页面稳定后再做下一个：
1. 体验「设计创意模式」
   - 新建任务，判断首页加载完成
   - 不写死固定入口，动态遍历所有分类，优先选择模板数量最多的日常任务分类；代码开发分类下仅网站设计有模板，其余子分类无模板直接跳过
   - 逐个判断分类下是否存在模板，跳过「生成图片」「生成视频」「品牌设计」等所有无模板分类
   - 判断二级菜单加载完成、下方模板列表出现
   - 选中模板点「做同款」，出现替换弹窗点替换
   - 判断提示词填入完成，点发送，验证会话发起成功，进入下一个任务
2. 探索优秀灵感
   - 鼠标hover左侧「更多」，等浮层弹出
   - 点灵感入口，等灵感广场加载
   - 选灵感卡片点入，等详情加载
   - 点「做同款」，等对话页打开提示词填入
   - 点发送，验证发起成功，进入下一个任务
3. 体验「资料库」
   - 点左侧资料库入口，等面板加载、树形菜单展开
   - 依次打开6份文档：每份等加载完成，滚动到最底部读完，再开下一份
   - 6份全部读完后，点最后一份文档底部「进一步了解WorkBuddy资料库」外链
   - 等新页面打开，将外链页面滚动到最底部读完
   - 验证完成，进入下一个任务
4. 体验「腾讯轻量云」专家
   - 打开专家中心，等页面加载
   - 搜索「腾讯轻量云」，等结果加载
   - 点召唤，完成授权（已登录无需扫码）
   - 等对话页打开，按普通专家规则处理
   - 点发送，验证发起成功，进入下一个任务
5. 体验「GLM-5.2」模型
   - 新建任务，等页面加载
   - 先切到其他免费模型，确认切换成功
   - 再切回GLM-5.2，确认切换生效
   - 输入一句话，点发送，验证发起成功，进入下一个任务
6. 使用5个模板
   - 新建任务，判断首页加载完成
   - 和设计创意模式逻辑一致，不写死固定入口，动态遍历所有分类，优先扫描模板最多的日常任务分类；代码开发分类下仅网站设计有模板，其余无模板分类直接跳过
   - 自动扫描所有带模板分类下的全部模板，读取账号级全局模板使用账本：灵感任务、设计创意模式以及其他所有任务里已经用过的模板统一标记，仅筛选该账号在任何任务里都未使用过的不同模板
   - 排除生成图片/生成视频/品牌设计等所有无模板分类
   - 判断二级菜单加载完成、模板列表正常显示
   - 依次选择5个未执行过的模板，逐个操作：
     选中模板点「做同款」，出现替换弹窗点替换，判断提示词填入完成，点发送，验证会话发起成功后，标记该模板已执行，再选下一个
   - 5个模板全部串行发完，进入下一个任务

#### 第三步：串行执行普通专家、专家团任务
1. 召唤5次普通专家
   - 打开专家中心「专家」tab，判断专家列表加载完成
   - 依次选5个该账号未召唤过的专家，逐个串行操作：保证专家直接完成交付，不出现反问、索要资料、要求确认方案的情况
   - 点发送验证发起成功，立刻召唤下一个，不等完整回复
   - 5个全部发完，进入下一个任务
2. 召唤3次专家团
   - 打开专家中心切「专家团」tab，等团队列表加载
   - 依次选3个该账号未召唤过的不同团队，逐个操作：
     点团队卡片召唤 → 勾选「我已知悉确认」→ 点继续使用，等对话页打开
     必须清空输入框原有预填引导语，只发「请让你们团队每个成员介绍一下自己的团队能力。」
   - 点发送验证发起成功，立刻召唤下一个，不等完整回复
   - 3个全部发完，进入下一个任务

#### 第四步：串行执行面板操作类任务
1. 体验「和平精英」主题
   - 点左下角头像进外观面板，等加载完成
   - 先选任意其他主题，确认切换生效
   - 再切回和平精英主题，确认切换生效
   - 关闭面板，进入下一个任务
2. 体验「发现应用」/企鹅教师助手
   - 点左上角「发现应用」，等列表加载
   - 点企鹅教师助手卡片，等应用打开，授权弹窗点跳过
   - 验证加载后退出，检查两个任务是否都计分，没计分重新进入一次
   - 完成后进入下一个任务
3. 尝鲜热门技能
   - 打开专家中心切「技能」tab，等列表加载
   - 点「我安装的」，选已安装技能点「使用/打开」
   - 确认技能唤起成功即计分，不需要发消息，进入下一个任务
4. 设置自动化任务
   - 点左侧定时任务入口，等页面加载，点添加
   - 填名称「每天提醒我喝水」、提示词「提醒我喝水。」，频率选未来日期
   - 勾选确认、选完全访问，点创建
   - 确认定时任务创建成功，**等服务端积分到账后**，再删除该定时任务
   - 完成后进入下一个任务

#### 第五步：被动累计任务最后检查（不提前跳过）
1. 桌面端对话1次：拉服务端进度，前面任务累计够直接标记完成；次数不足补1轮完整对话（用户发一句、AI回一句），验证计分
2. 和AI聊天5次：拉服务端进度统计完整对话轮数，前面累计够直接标记完成；轮数不足补够对应轮数完整对话，验证计分

#### 第六步：统一复核与收尾
1. 再次拉取服务端全部任务进度
2. 未计分任务自动补做，最多3轮
3. 一键领取所有「待领取」状态积分，确认全部到账
4. 清理本次新建临时会话，保留用户原有内容

#### 第七步：账号完成判断
- 判断：所有可自动化任务全部计分、所有积分全部到账？
  - 否：继续补做未完成项，不切换账号，不按时间强制切走
  - 是：记录本账号当日完成，切换下一个账号，重复UI全流程

---

### 最终收尾
1. 所有账号遍历完成
2. 全账号二次扫尾，领取所有漏领积分
3. 切回启动前的账号
4. 前端展示完成结果与本次总积分，流程结束

---

## 四、停止任务流程
1. 用户点击停止按钮，设置全局停止标记
2. 每个任务关键节点检查停止标记
3. 收到停止指令后，完成当前最小操作步骤，立刻退出
4. 自动切回启动前的账号
5. 不杀客户端进程、不清理用户缓存、不重载页面、不删除用户原有数据
6. 前端展示「已停止」状态，保留当前进度与日志。

## 五、断点续传规则
1. 按日期维度记录账号完成状态，当日有效
2. 中途重启/停止后，再次执行自动跳过当日已完成账号，从断点继续
3. 第二天自动重置所有完成状态，重新执行全流程。
